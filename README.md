# Necropolis: Rise of the Undying

A free idle game about building an undead empire. Raise Skeletons, recruit stronger undead, claim territory and ascend for permanent bonuses.

[Play in your browser](https://apoped.itch.io/necropolis-rise-of-the-undying)

## Download

[Download v2.5.8](https://github.com/GravelRockStudios/test/raw/refs/heads/main/Necropolis_2.5.8_GAME_UPLOAD.zip)

Extract the ZIP and open `index.html` to play locally. The same ZIP can be uploaded to itch.io as an HTML game.

Your progress saves in your browser. Use Options to export a save before changing browsers, clearing browser data or replacing a local copy of the game.

## Latest update

Recruitment and upgrades are together again. Each tier's upgrades sit below its recruitment controls, with more space between sections and a single column on smaller screens.

The ZIP includes release notes and the game files. Older downloads remain here for players who need them.
